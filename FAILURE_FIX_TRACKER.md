## 2. Failure Categories Key
1. **Selenium Locator Problems:** Invalid XPath/CSS, compound classes rejected under Selenium 4 W3C compliance.
2. **Explicit Wait & Synchronization Problems:** Race conditions, AJAX drop-down latency, missing `ExpectedConditions`.
3. **Incorrect Assertions:** Weak string comparison or checking element innerText on `<input>` fields instead of `value` attribute.
4. **Login/Session Handling:** Expired session cookies, tearDown collision across class instances.
5. **Missing Database Preconditions:** Missing foreign keys, lookup tables (languages, memberships, locations), missing employee records.
6. **Invalid or Duplicate Test Data:** Hardcoded employee names/IDs not matching database records or duplicate key collision.
7. **Test Dependency & Execution-Order Cascades:** `dependsOnMethods` cascade failures when prerequisite tests failed.
8. **Application-Level Defects:** PHP strict datetime format mismatch in `EmployeeEventService.php` and MySQL 5.7+ `ONLY_FULL_GROUP_BY` strict mode.
9. **Configuration Problems:** Incorrect database credentials, application baseUrl mismatch.
10. **Swallowed Exceptions & Exception Masking:** Empty `catch(Exception e)` blocks hiding genuine stack traces.
